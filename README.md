# Aurum Market

Vercel-ready Next.js landing page for a modern jewellery, gold-buying, repair and custom-design shop.

## Publish it

1. Create a new GitHub repository and upload these files.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Vercel detects Next.js automatically; select **Deploy**.

## Local preview

```bash
pnpm install
pnpm dev
```

Before publishing, confirm the listed business hours and replace the placeholder stock photography if desired.
